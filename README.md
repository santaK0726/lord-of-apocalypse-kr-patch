# Lord of Apocalypse 한글패치 v0.5 (시험 배포)

PSP 일본판 NPJH50503용입니다. 일본어만 한국어로 교체하며 영어는 원본을 유지합니다.
전체 플레이 검수 전의 시험 배포본입니다. 사용자가 초반부 한글 표시가 정상임을 확인했습니다.
후반부 줄 넘침, 번역 표현, 전투·보스 이미지, 저장/이름 입력 등의 전체 검수는 완료되지 않았습니다.

배포 파일은 [Releases의 v0.5](https://github.com/santaK0726/lord-of-apocalypse-kr-patch/releases/tag/v0.5)에서 `Lord-of-Apocalypse-Korean-v0.5.zip`을 받으세요. GitHub 자동 생성 Source code.zip에는 차분 데이터가 없습니다.

## 적용 방법 (Windows)

1. ZIP 파일을 전부 같은 폴더에 압축 해제합니다.
2. 수정하지 않은 일본판 ISO를 준비합니다. 게임 ISO는 제공하지 않습니다.
3. ISO를 Apply-Patch.bat 위로 끌어 놓거나, 배치 파일을 실행하고 ISO 경로를 입력합니다.
4. 성공 메시지가 나오면 원본과 같은 폴더에 생성된 `Lord of Apocalypse - Korean v0.5.iso`를 사용합니다.

원본 파일을 덮어쓰지 않습니다. 이미 출력 파일이 있으면 중단합니다.
원본·패치·출력 SHA-256을 검사하며, 다른 판본/기존 패치 ISO는 거부합니다.
실패 시 .partial 파일을 사용하지 마세요. 배포 파일을 신뢰하는 경우에만 실행하세요.
Python이나 별도의 패치 프로그램은 필요하지 않습니다(Windows PowerShell/.NET 사용).

## 실행 환경 및 제한

PPSSPP 중심 시험본입니다. PPSSPP 정식 배포본의 기본 일본어·한국어 폰트를 사용하세요.
사용자 교체 폰트가 적용된 환경에서는 일본어/한글 표시가 깨질 수 있습니다.
기존 데이터 인스톨 파일을 사용하는 경로와 실기 PSP는 지원 검증 전입니다.
세이브 호환성 전체 검증 전이므로 기존 세이브를 먼저 별도로 백업하세요.
게임 비밀번호 등 입력값은 동작 보존을 위해 일부 원문을 유지합니다.
보스 이름 이미지 일부는 글자별 등장 대신 단어 단위로 표시됩니다.

원본 ISO SHA-256: `3a4d63713880dfb67ade00b6a912ac4975847cec06b1ab341b65963f328e1c93`
결과 ISO SHA-256: `9186495574ab17032b27927c485a4377e29626bdb7b824e88ed781b1d2ab91b4`

게임과 상표의 권리는 각 권리자에게 있습니다. 비공식 팬 번역 시험 패치입니다.
원본 ISO, 에뮬레이터, 폰트, 추출한 게임 파일은 포함하지 않습니다.
